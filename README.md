# Personnel Management System 👨‍💼

## 📌 Project Description
This project is a desktop application developed to manage personnel records using C# and SQL Server.

## 🧠 Technologies Used
- C#  
- Windows Forms  
- SQL Server  

## 📊 Features
- Add, update, delete personnel  
- List and search records  
- Data visualization (statistics & charts)  
- User-friendly interface  

## 🎯 Goal
To develop a basic automation system for managing personnel data efficiently.

## 🚀 Status
Completed as a database-driven desktop application project.
